## Activity Summary
1. **STT Service Deployment Fix (`vietbridge-stt`):**
   - **Issue:** Render build failed with `Could not open requirements file: [Errno 2] No such file or directory: 'requirements.txt'`.
   - **Resolution:** Identified that `requirements.txt` resides inside `stt_service/` rather than the repository root. Configured Render settings with `Root Directory: stt`, `Build Command: pip install -r stt_service/requirements.txt`, and `Start Command: python -m stt_service.server`. Enforced `PYTHON_VERSION=3.11.9` via environment variables.

2. **Backend Gateway Deployment Fix (`vietbridge-backend`):**
   - **Issue:** Nest build failed with `sh: 1: nest: not found` despite successful `npm install`.
   - **Resolution:** Diagnosed that setting `NODE_ENV=production` caused npm to skip `devDependencies` (`@nestjs/cli` and `typescript`). Updated **Build Command** to `npm install --include=dev && npm run build` and **Start Command** to `node dist/main`.

3. **Frontend Static Site Deployment Fix (`vietbridge-demo` / `vietbridge-apt`):**
   - **Issue:** TypeScript build (`tsc -b && vite build`) failed with `error TS2322: Type 'string | null' is not assignable to type 'string | undefined'` in `utteranceManager.ts` and missing modules (`uuid`, `socket.io-client`, `onnxruntime-web`).
   - **Resolution:**
     - Modified `voice/src/utterance/utteranceManager.ts` (L169) to use nullish coalescing (`this.activeContinuationId ?? undefined`) to satisfy strict TypeScript checking.
     - Updated Render **Build Command** to `npm install --prefix ../voice && npm install && npm run build` to ensure local workspace package dependencies inside `../voice` are fully installed before building the frontend bundle.

4. **Runtime Connection & Architecture Troubleshooting:**
   - **Frontend-Backend Connection (`BACKEND_UNAVAILABLE`):** Clarified that Vite embeds environment variables (`VITE_BACKEND_API_URL`, `VITE_BACKEND_WS_URL`) into static JavaScript bundles at compile time. Instructed user to run **Manual Deploy → Clear build cache & deploy** after setting environment variables so the frontend connects to `https://vietbridge-backend.onrender.com` instead of fallback port `3000`.
